# 改动后的回归检查清单

每次改完代码、重新构建后，跑一遍这份清单。运行 `DeepSeek Chat.exe --selftest`，
程序会自检、截图到 `data\selftest.png` 后自动退出，并把结果打到 `data\main.log`。

## 一、核心能力（绝不能回退）

| # | 检查项 | 怎么看 | 合格值 |
|---|---|---|---|
| 1 | 应用能起来 | selftest 的 `ok` | `true` |
| 2 | 用的是固定 origin | `origin` | `app://chat` |
| 3 | 界面渲染出来了 | `rendered` | `true` |
| 4 | 对话库可读写 | `idbStores` | 含 sessions / sessionSummaries / files / filesStaging / sessionsStaging |
| 5 | **跨启动持久化** | 连续跑两次，第二次的 `sessionProbe` | 非 null（等于上一次写入的时间戳） |
| 6 | **API Key 自动注入** | `apiKeyInjected` | `true` |
| 7 | 数据目录在程序旁 | `dataDir` | 程序目录下的 `data` |

## 二、外观（容易互相打架，重点回归）

| # | 检查项 | 怎么看 | 合格值 |
|---|---|---|---|
| 8 | 标题栏着色成功 | 日志里的 `caption colors: ... results=` | `0,0,0` |
| 9 | 跟随系统时颜色一致 | selftest 的 `theme.consistent` | `true` |
| 10 | 改偏好反应快 | `preferenceLatencyMs` | < 300（当前 83） |
| 11 | 浅色下菜单栏不变黑 | 切到浅色后截窗口图看菜单栏 | 浅底黑字 |
| 12 | 深浅色切换后菜单栏不滞留 | 来回切两次 | 每次都跟着变 |
| 12b | **焦点切换后标题栏颜色不变** | 点开记事本再切回来（重复 2 次），看标题栏 | 始终是界面色，不闪成系统色 |
| 12c | **深浅色切换有渐变** | selftest 的 `fadeCheck` | `overlay=true`、`midOpacity` 明显小于 1、`removed=true` |

## 三、交互（改外观时最容易被误伤）

| # | 检查项 | 合格值 |
|---|---|---|
| 13 | 点「设置」弹窗，遮罩正常、无割裂 | 顶部和内容一起变暗，按钮不被单独割裂 |
| 14 | 导出对话只弹 **一个** 保存框 | 1 个 |
| 14b | **侧边栏导入/导出按钮接线** | `DeepSeek Chat.exe --transfertest` | `exportButton/fileInput/confirmShown/confirmClosed` 全为 true，`DOWNLOAD_COUNT 1` |
| 14c | **“更多”菜单不飘到左上角** | `DeepSeek Chat.exe --menutest` | `anchorAfter` 为 0×0 时 `menuAfter` 仍等于 `menuBefore`，`stable: true` |
| 15 | 导出取消后不产生空文件 | 无 |
| 16 | 麦克风可用、其它权限被拒 | 语音输入可用 |
| 17 | 消息里的外链走系统浏览器 | 不出现应用内新窗口 |
| 18 | 窗口大小/位置重启后保持 | 保持 |

## 四、已经删掉的东西（别又加回来）

| 项 | 现状 |
|---|---|
| 自动备份 / 立即备份菜单 | **已移除**，数据只存一份 |
| 自绘标题栏（WCO） | **已移除**，改用原生标题栏 + DWM 上色 |
| 本地 API 反向代理 | **不需要**，前端直连官方 API |

## 五、架构约束（别退回去）

| 约束 | 说明 |
|---|---|
| **不许用轮询采样应用状态** | 应用侧设置变化由 `settings.ts` 主动派发 `ds:settings` 事件（theme / apiKey），外壳监听即可 |
| 外壳代码里不应出现 `setInterval` | 当前为 0 处；事件源：DOM 变化、媒体查询、窗口焦点/显示/还原、`ds:settings` |
| 焦点后的延迟重写只允许"一次性" | Windows 重绘标题栏是异步的，事件后 +400ms / +1200ms 各补一次，属于事件补偿，不是轮询 |
| 颜色只在变化时记日志 | 焦点切换会频繁重写同一组颜色，日志必须去重 |

## 六、已知的环境依赖

| 依赖 | 影响 | 失效时表现 |
|---|---|---|
| Windows 11 (22000+) | 标题栏才能上色 | 回退系统配色，功能不受影响 |
| koffi 原生模块可加载 | DWM 调用 | 同上，回退系统配色 |
| 简体中文/英文语言包 | 界面语言 | 其它语言回退英文 |
